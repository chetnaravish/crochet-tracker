Which stitch should I learn first?

Start with the chain, then single crochet. If you want to make amigurumi, learn the magic ring, increase and decrease next. Those five are enough for a whole toy. For blankets and granny squares, add half double and double crochet.

When you meet an unfamiliar abbreviation, check the crochet abbreviations chart.
